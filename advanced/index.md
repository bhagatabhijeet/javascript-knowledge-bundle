# Advanced Topics

Advanced concepts for enterprise JavaScript applications including asynchronous programming, modular architecture, and performance patterns.

1. [Async JavaScript](./async.md) - Learn the event loop, promises, and async/await for working with asynchronous tasks in JavaScript.
2. [ES modules](./modules.md) - Organize code with imports and exports using the JavaScript module system.
3. [Debouncing](./debouncing.md) - Delay running a function until a rapid burst of calls goes quiet, so expensive work only happens once instead of on every single event.
