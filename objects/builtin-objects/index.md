# Built-in Objects

JavaScript ships with a handful of global objects that are always available, without any import — no need to build these yourself.

1. [Math](./math.md) - Use the built-in Math object for constants and functions like rounding, random numbers, and min/max.
2. [String](./string.md) - Work with text using string primitives, their built-in methods, and the String wrapper object.
3. [Date](./date.md) - Represent and work with points in time using JavaScript's built-in Date object.
