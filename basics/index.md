# Basics

Core JavaScript building blocks: variable and constant declarations, data types, dynamic typing, objects, arrays, and functions.

1. [Variables](./variables.md) - Declare and initialize variables in JavaScript using let, including naming rules and best practices.
2. [Constants](./constants.md) - Declare non-reassignable identifiers using the const keyword, and understand when to use const vs let.
3. [Variable Declaration: var, let, and const](./variable-declaration.md) - Compare the three ways to declare a variable in JavaScript — var, let, and const — and when to use each one.
4. [Primitive Types](./primitive-types.md) - The primitive types in JavaScript (string, number, boolean, undefined, null, symbol, bigint) and their value semantics.
5. [Dynamic Types](./dynamic-typing.md) - How JavaScript determines variable types at runtime dynamically and how to inspect types using the typeof operator.
6. [Objects](./objects.md) - Work with reference types using JavaScript object literals, dot notation, and bracket notation.
7. [Arrays](./arrays.md) - Store and manage ordered lists of items in JavaScript using arrays, index access, and length.
8. [Functions](./functions.md) - Define reusable blocks of logic using function declarations, parameters, and arguments.
9. [Types of Functions](./function-types.md) - Categorize functions by purpose into those that perform a task and those that calculate and return a value.
