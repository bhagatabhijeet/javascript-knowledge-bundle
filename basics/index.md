# Basics

Core JavaScript building blocks: variable and constant declarations, data types, dynamic typing, objects, arrays, and functions.

1. [Variables](./variables.md) - Declare and initialize variables in JavaScript using let, including naming rules and best practices.
2. [Constants](./constants.md) - Declare non-reassignable identifiers using the const keyword, and understand when to use const vs let.
3. [Variable Declaration: var, let, and const](./variable-declaration.md) - Compare the three ways to declare a variable in JavaScript — var, let, and const — and when to use each one.
4. [Local vs Global Scope](./local-vs-global-scope.md) - Understand what makes a variable globally visible versus local to a single function, and what happens when the two share a name.
5. [Primitive Types](./primitive-types.md) - The primitive types in JavaScript (string, number, boolean, undefined, null, symbol, bigint) and their value semantics.
6. [Dynamic Types](./dynamic-typing.md) - How JavaScript determines variable types at runtime dynamically and how to inspect types using the typeof operator.
7. [Objects](./objects.md) - Work with reference types using JavaScript object literals, dot notation, and bracket notation.
8. [Arrays](./arrays.md) - Store and manage ordered lists of items in JavaScript using arrays, index access, and length.
9. [Functions](./functions.md) - Define reusable blocks of logic using function declarations, parameters, and arguments.
10. [Types of Functions](./function-types.md) - Categorize functions by purpose into those that perform a task and those that calculate and return a value.
