# Operators

Perform calculations, assign values, compare expressions, and make decisions with JavaScript operators.

1. [JavaScript Operators](./javascript-operators.md) - An introduction to operators in JavaScript, how operands and operators interact, and categories of operators.
2. [Arithmetic operators](./arithmetic-operators.md) - Perform numeric calculations with JavaScript's arithmetic operators, including exponentiation and remainder.
3. [Assignment operators](./assignment-operators.md) - Assign and update values with = and its compound arithmetic, logical, and nullish-coalescing forms.
4. [Comparison operators](./comparison-operators.md) - Compare values with relational operators and understand how JavaScript coerces operands during comparison.
5. [Equality operators](./equality-operators.md) - Compare values for equality with == and ===, and understand why strict equality is preferred.
6. [Ternary operator](./ternary-operator.md) - Write concise conditional expressions with JavaScript's only three-operand operator, condition ? a : b.
7. [Logical operators](./logical-operators.md) - Combine and short-circuit expressions with &&, ||, !, and the nullish coalescing operator ??.
8. [Bitwise operators](./bitwise-operators.md) - Manipulate integers at the bit level with JavaScript's bitwise AND, OR, XOR, NOT, and shift operators.
9. [Operator precedence](./operator-precedence.md) - Understand the order JavaScript evaluates operators in a compound expression, and when to use parentheses.
