# Operators

Perform calculations, assign values, compare expressions, and make decisions with JavaScript operators.

1. [Arithmetic Operators](./arithmetic-operators.md) - Perform numeric calculations with JavaScript's arithmetic operators, including exponentiation and remainder.
2. [Assignment Operators](./assignment-operators.md) - Assign and update values with = and its compound arithmetic, logical, and nullish-coalescing forms.
3. [Comparison Operators](./comparison-operators.md) - Compare values with relational operators and understand how JavaScript coerces operands during comparison.
4. [Equality Operators](./equality-operators.md) - Compare values for equality with == and ===, and understand why strict equality is preferred.
5. [Ternary Operator](./ternary-operator.md) - Write concise conditional expressions with JavaScript's only three-operand operator, condition ? a : b.
6. [Logical Operators](./logical-operators.md) - Combine and evaluate expressions using logical AND, logical OR, and logical NOT.
7. [Logical Operators with Non-Boolean](./logical-operators-with-non-booleans.md) - Evaluate truthy and falsy expressions and leverage short-circuit evaluation for fallback values.
8. [Bitwise Operators](./bitwise-operators.md) - Manipulate integers at the bit level with JavaScript's bitwise AND, OR, XOR, NOT, and shift operators.
9. [Operator Precedence](./operator-precedence.md) - Understand the order JavaScript evaluates operators in a compound expression, and when to use parentheses.
