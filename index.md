# JavaScript Knowledge Bundle

**javascript-knowledge-bundle** — JavaScript fundamentals, control flow, operators, data structures, and practical exercises, built to exercise the OKF import pipeline in obviewus and validate concept rendering in a graph view. Owner: `human:bhagatabhijeet`. Created 2026-08-29.

# Sections

1. [Getting Started](getting-started/) - Foundational setup, browser runtime, separation of concerns, and Node.js.
2. [Basics](basics/) - Variables, constants, primitive types, dynamic typing, objects, arrays, and functions.
3. [Operators](operators/) - Arithmetic, assignment, comparison, equality, ternary, logical, and bitwise operators, plus operator precedence.
4. [Control Flow](control-flow/) - Conditional statements (if-else, switch) and loops (for, while, do-while, for-in, for-of).
5. [Objects](objects/) - Object-oriented patterns, property manipulation, methods, and reference semantics.
6. [Arrays](arrays/) - Ordered collections, searching, adding, removing, and iterating over array elements.
7. [Functions](functions/) - Declarations, expressions, getters, setters, and factory functions.
8. [Advanced](advanced/) - Asynchronous JavaScript and ES module architecture.
9. [Quiz](quiz/) - Knowledge checks and multiple-choice quizzes with detailed explanations.
10. [Assets](assets/) - Code snippets, exercises, and bundle images.

## Notes

The bundle intentionally keeps metadata sparse but structured so downstream tools can parse it reliably. Bundle-level descriptive fields (title, description, owner, created) live in this body, not frontmatter, since OKF v0.2 §8 permits only an `okf_version` key in a root `index.md`'s frontmatter.
