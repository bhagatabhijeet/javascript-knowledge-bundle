# Getting Started

The foundational setup and mental models needed to understand and write modern JavaScript.

1. [What is JavaScript](./what-is-javascript.md) - An introduction to JavaScript, what you can build with it, where it runs, and the relationship between JavaScript and ECMAScript.
2. [Setting up the Development Environment](./setting-up-the-development-environment.md) - Prepare a practical JavaScript workspace with Node.js, a code editor, a project folder, and a local development server.
3. [JavaScript in Browsers](./javascript-in-browsers.md) - How JavaScript runs inside web browsers, interacts with the Document Object Model (DOM), and is included in HTML documents.
4. [Separation of Concerns](./separation-of-concerns.md) - Organize web applications by separating HTML content from JavaScript behavior using external script files.
5. [JavaScript in Node](./javascript-in-node.md) - Install Node.js and run JavaScript outside the browser, including modules, globals, and npm basics.
