# JavaScript Operators Quiz: Questions

Test your knowledge of JavaScript operators with these 10 multiple-choice questions.

---

### Question 1
What is the result of `true && false`?
- a) `true`
- b) `false`
- c) `null`
- d) `undefined`

---

### Question 2
What is the result of `(true && false) || true`?
- a) `true`
- b) `false`
- c) `null`
- d) `undefined`

---

### Question 3
What is the value of `y`?
```js
let x = 10;
let y = (x > 10) ? 1 : 0;
```
- a) `10`
- b) `1`
- c) `0`
- d) `11`

---

### Question 4
What is the value of `x`?
```js
let x = (2 + 3) * (4 + 5);
```
- a) `45`
- b) `25`
- c) `20`
- d) `40`

---

### Question 5
Which expression returns `true`?
- a) `'1' === 1;`
- b) `1 == 1`
- c) `1 === 1`
- d) `b and c`

---

### Question 6
What is the value of `x`?
```js
let x = (1 == true);
```
- a) `1`
- b) `true`
- c) `false`
- d) `undefined`

---

### Question 7
What is the value of `y`?
```js
let x = 10;
let y = (x > 5) && (x < 15);
```
- a) `10`
- b) `5`
- c) `15`
- d) `true`

---

### Question 8
What is the value of `x`?
```js
let x = 5;
x += 3;
```
- a) `3`
- b) `8`
- c) `15`
- d) `5`

---

### Question 9
What is the value of `y`?
```js
let x = 10;
let y = x++;
```
- a) `10`
- b) `11`
- c) `12`
- d) `13`

---

### Question 10
What is the value of `y`?
```js
let x = 1;
let y = x !== 2;
```
- a) `1`
- b) `2`
- c) `false`
- d) `true`
